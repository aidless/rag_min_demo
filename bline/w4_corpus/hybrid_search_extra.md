# 混合检索补遗

在纯稀疏与纯稠密之间还有一条中间路线。稀疏高维表示用维度极高的稀疏向量把词与语义锚点关联起来，既保留词项匹配的能力，又通过锚点获得一定的语义泛化，代价是索引体积随维度膨胀。BM25 这类经典稀疏方法完全不建模语义，n-gram 扩展在中文这类没有天然词边界的文本上比英文更依赖分词质量，字符二元组能绕过分词，但会把无关的相邻字也纳入匹配。

稠密方法的长处是同义与近义表述之间不需要字面重合，短查询也能命中长文档，代价恰恰是对专有名词、型号、代码符号这类低频精确 token 不敏感——它们在语料里罕见，训练时被学到的嵌入缺乏区分度。稀疏方法在这些 token 上反而最稳，因为逆文档频率天然给罕见词更高的权重。

这三条路线的失效模式互不相同，混合才稳：稀疏靠词面、稠密靠语义、锚点靠结构。当一条查询同时包含罕见专名和口语化描述时，单独任何一路都会漏掉一半意图。需要注意的是混合并不是把三路分数直接相加就完了，每一路的分数分布形状不同，必须各自做归一化之后再融合，否则样本量最大的一路会压倒其他路。融合权重同样需要随语料标定，固定权重在换语料后往往不再最优。
