# 提示与模板

提示模板是 RAG 里最常被手工调整、也最少被系统评测的部分。同一套检索结果，换一个模板能把准确率拉高几个百分点，代价是没有任何记录说明改了什么，于是这次提升无法在别的语料上复现。模板的效果依赖于模型，换模型要重新标定；它还依赖任务，闭集事实问答和需要组织答案的写作任务对模板的要求完全不同。

模板里最影响准确率的是答案格式的约束和示例的数量。约束答案长度或形式能减少模型的自由发挥，代价是答案超出模板能表达的范围时会被截断。示例数量增加能稳定格式，但超过某个点后收益迅速衰减，而每次调用都要多付一次示例的 token 成本。示例还有一个隐蔽的偏置：示例里出现的文档内容会被模型优先引用，即使真实答案在检索结果之外，于是系统倾向于复述示例而不是根据当前检索作答。

一个可控的做法是把模板与检索结果一起版本化，把模板哈希和检索参数写进每次评测的记录里。这样任何一次准确率数字都能追溯到它当时用的模板和参数，而不是一个孤立的数。改模板时按同样的评测集跑新旧两版，看差值而不是看绝对值，并把评测集划分成调模板用的开发集和不参与调模板的保留集，两者的差距就是模板过拟合的程度。
